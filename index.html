Straight answers

Does it spy on me?

No. The Android app reads which screen is open in five apps — only to spot short-video players. No accounts, no servers, no analytics, no ads. The code is open source; go read it.

Why can't the iPhone version do what Android does?

Apple provides no API for one app to see or change another app's interface — there is no iOS equivalent of Android's AccessibilityService. So on iPhone you get a stripped built-in browser plus optional whole-app Screen Time locks. Anyone promising more on iOS is selling you something.

What about TikTok?

TikTok is 100% short-form video — there is no "TikTok without short videos." The TikTok switch blocks (Android) or locks (iOS) the app itself.

Can my kid just turn it off?

Yes — anyone with the device PIN can disable the permissions. This is a friction tool for willing users, not parental-control software or a kiosk.

Will it break when YouTube updates?

Possibly, temporarily. Detection relies on YouTube/Instagram's internal layouts, which change without notice. Rule updates ship without an app update — the app fetches the new bundle itself.

Is it really free?

MIT-licensed, yes. No premium tier, no "pro" unlock, no ads. If someone charges you for Doomscroll Guard, it's a scam — get it from the GitHub repo.
